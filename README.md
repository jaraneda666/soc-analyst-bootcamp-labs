# SOC Analyst Bootcamp Labs & CTI

Proyectos de laboratorio y ejercicios de análisis de seguridad del Bootcamp Analista SOC Nivel 2. Incluye despliegue de plataforma MISP en contenedores, modelado de eventos con taxonomías TLP/PAP, correlación MITRE ATT&CK y ejercicios de Threat Hunting.

---

## Arquitectura y Componentes

- **Plataforma CTI:** Stack de MISP 2.5 contenedorizado con Nginx, MariaDB y Redis.
- **Formatos:** Modelado de amenazas bajo especificaciones STIX 2.1 e integración de feeds OSINT.
- **Análisis de eventos:** Casos prácticos de suplantación bancaria y extracción de IoCs.
